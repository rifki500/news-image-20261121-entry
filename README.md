One image summing up the world news of **Saturday, 21 November 2026**:
30 stories, from COP31 running into overtime in Antalya and two tankers
struck in the Strait of Hormuz, to Mexico capturing "El Chapo Isidro",
BepiColombo reaching Mercury, and a dengue breakthrough in Brazil.

Every story in the image happened, or was first reported, on 21 November
2026 — verified against that day's reporting (Reuters, AP, AFP, USGS, ESA,
UKMTO and others).

## Entry

- `entry.png` — the front page (1024x1024 PNG, under 1 MiB)
- `main.py` — Python 3.13, standard library only; copies `entry.png` to
  `$MAKEFUN_OUTPUT_DIR` (or `/output` if unset) as `entry.png`

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Two runs write byte-identical output.
